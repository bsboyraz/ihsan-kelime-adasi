# Ihsan'in Kelime Adasi

5. sinif ogrencisi Ihsan icin hazirlanmis sesli Ingilizce kelime ogrenme oyunu.

## Icerik

- 16 kategori
- 920 ogretilebilir oge
- Kelime, kalip ve ornek cumle calismalari
- Normal ve yavas Ingilizce okunus
- Anlamini bul, dinle ve sec, yazma, eslestirme ve cumle tamamlama oyunlari
- 2-4 kisilik ayni cihazda yaris modu
- Tekrar cantasi ve gunluk 5 kelime hedefi

## Ogrenme Mantigi

DEHB dikkate alinarak ana kelime havuzu buyuk tutulur, ama cocuk ekranda kucuk gorevler halinde ilerler:

1. Tema secilir.
2. Mini gorevde 5-10 oge calisilir.
3. Once kelime listesi incelenir.
4. Sonra kisa oyunlar acilir.
5. Cumleli sorular en son kullanilir.

## GitHub Pages

Bu proje statik HTML/CSS/JS ile calisir. GitHub Pages icin:

1. Repository Settings bolumune gir.
2. Pages menusunu ac.
3. Source olarak `main` branch ve `/root` sec.
4. Kaydedince oyun birkac dakika icinde yayinlanir.

## Dosyalar

- `index.html`: uygulama giris sayfasi
- `style.css`: tasarim
- `app.js`: oyun mantigi
- `data.js`: tema tema kelime ve kalip verisi
